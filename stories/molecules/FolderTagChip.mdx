# FolderTagChip (Figma: `molecule/FolderTagChip`, `558:8055`)

## Uso

Chip para marcar/filtrar por pasta — ícone de pasta, rótulo e botão opcional
de remoção. Use `removable` quando o chip representar um filtro ativo que o
usuário pode limpar; sem a prop, é só um rótulo informativo.

<Controls of={FolderTagChipStories.Default} />

## Anatomia

Ícone de pasta + rótulo + botão de remover opcional (`removable`). Também
tem uma prop `isExpanded` — quando expandido, o ícone e o rótulo ficam
visíveis e o rótulo perde o truncamento.

### Colapsado (`isExpanded=false`, o padrão)

<Canvas of={FolderTagChipStories.Collapsed} />

**Decisão humana em 2026-09-25:** implementação literal do Figma (`568:8695`,
`State=Default, Expanded=false`) — o ícone de pasta e o rótulo ficam com
`opacity: 0`, e só o botão de remover aparece. Nenhuma tela do produto usa
este chip hoje, então essa fidelidade não afeta nenhuma composição real. O
nome da pasta continua no DOM (não `aria-hidden`), para o leitor de tela
anunciar mesmo com o chip visualmente vazio.

<Canvas of={FolderTagChipStories.Expanded} />

### Tipografia

Rótulo do chip usa 14px, acima do piso mínimo de 11px definido para
microtexto decorativo (tags/badges).

## Estados

<Canvas of={FolderTagChipStories.Selected} />

- `default`
- `hover`
- `selected`
- `disabled`

| Estado | Tratamento |
| --- | --- |
| Default (`State=Default`) | Chip em repouso |
| Hover (`State=Hover`) | Destaque do chip e do X (no Dark, zinc-800 → 700) |
| Pressed (`State=Pressed`) | Fundo do selecionado no `:active` |
| Selecionado (`selected`) | Com `onClick`, o chip vira alternância (`role="button"`, Enter/Espaço, `aria-pressed`) |
| Disabled | `aria-disabled`, sem clique |
| Foco | 🧩 Anel de 3px `Brand/Primary/Action` a 50%, só pelo teclado |

## Terminologia

O rótulo é conteúdo livre (nome de pasta escolhido pelo usuário), não
texto fixo de produto.
