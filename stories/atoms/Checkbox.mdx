# Checkbox (Figma: `atom/Checkbox`, `3051:9590`)

✅ Figma-confirmado: `atom/Checkbox` (`3051:9590`), KanDrive V0.2.1.

## Uso

Seleção múltipla em listas, por exemplo nos arquivos de "Gerir espaço" (`CleanSpaceListSelection`). O checkbox não tem texto visível próprio, então `aria-label` é obrigatório.

### Acessibilidade

É um `<button role="checkbox" aria-checked>`: responde a clique, Espaço e Enter, e o leitor de tela anuncia "caixa de seleção, marcada / não marcada".

## Estados

Desmarcado · Marcado · Hover · Active · Focus (anel, só pelo teclado) · Disabled (50%). Hover, active e foco são extensão de engenharia (Regra 8), porque o Figma não tem eixo `Hover`.

| Estado | Tratamento |
| --- | --- |
| Desmarcado / Marcado | Figma `Selected=false/true` |
| Hover 🧩 | Fundo um tom acima (marcado: `brand-teal-action/90`) — Regra 8 |
| Pressed 🧩 | Fundo dois tons acima (marcado: `brand-teal-action/80`) — Regra 8 |
| Foco 🧩 | Anel `ring-3 brand-teal-action/50`, só pelo teclado (Regra 8) |
| Disabled 🧩 | 50% de opacidade, sem ponteiro (Regra 8) |
| Transição | Troca de cor animada |

## Terminologia

Sem texto fixo de produto — o nome acessível (`aria-label`) vem de cada uso.
