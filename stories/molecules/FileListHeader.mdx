# FileListHeader (Figma: `molecule/FileList/Header`, `1421:19184`)

## Uso

Cabeçalho de coluna acima de [`molecule/FileList`](./FileList.mdx) — mesma
largura máxima (1025px), para alinhar colunas visualmente. Use sempre
junto de `FileList` no formato `list` — sem sentido isolado.

<Controls />

## Formatos

| Formato | Composição |
| --- | --- |
| `home` (padrão) | 1 linha com borda inferior: "Nome" + botão "Armazenamento" com seta |
| `storage-status` | 2 linhas: linha de coluna ("Nome" / "Proprietário" / "Tamanho do Arquivo") + linha de data (padrão "Hoje") |

<Canvas of={FileListHeaderStories.StorageStatus} />

## Estados

Cabeçalho estático, sem interação além do botão de ordenação (formato
`home`) — a ordenação em si não está implementada.

## Terminologia

"Nome"/"Armazenamento"/"Proprietário"/"Tamanho do Arquivo"/"Hoje" são
vocabulário de cabeçalho de tabela, sem restrições de terminologia
aplicáveis.
