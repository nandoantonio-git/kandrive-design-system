# ActionPill (Figma: `molecule/action-pill`, `1421:19027`)

## Uso

Pílula de ações principais exibida no header. Use quando precisar agrupar
2-3 ações de escopo global (ajuda, configurações, conta) num único bloco
visual no topo da tela — não é pra ações contextuais de uma tela específica.

<Canvas of={ActionPillStories.Default} />
<Controls />

## Anatomia

Três ícones dentro de uma pílula com fundo Liquid Glass: ajuda ("?"),
configurações (engrenagem) e conta (silhueta de pessoa). A API expõe uma
lista genérica de ações (`actions: { name, label, onClick }[]`) reutilizando
`atom/Icon`, então o conjunto exato de ações é configurável por quem usa o
componente.

## Estados

- `default`
- `disabled` (opacidade reduzida, ações desabilitadas)

<Canvas of={ActionPillStories.Disabled} />

## Terminologia

Não renderiza texto próprio — o `label` de cada ação vira `aria-label`
(acessibilidade), não texto visível.
