# TagOrgMode

Figma: [`atom/TagOrgMode`](https://www.figma.com/design/2g7udqxWbGA8F9Or7PGNg3/KanDrive-V0.2.1?node-id=309-14704)

## Uso

Tag que identifica o modo de organização ativo (Data/Livre/Projeto/Tipo) — usada nos fluxos de criação/edição de template de organização, para deixar claro qual critério está sendo aplicado. Aparece em `organism/OrganizeFreeModeCanvas`.

## Anatomia

### Modos

| Valor da prop `mode` | Rótulo exibido |
| --- | --- |
| `free` (padrão) | Modo Livre |
| `date` | Data |
| `project` | Projeto |
| `type` | Tipo |

## Estados

Elemento de exibição estática — sem hover/pressed/disabled próprios, é um rótulo do sandbox de organização. Sem estados interativos.

## Terminologia

"Modo Livre", "Data", "Projeto", "Tipo" — nenhum aparece nas listas da Regra 5 (nem aprovado nem proibido).
