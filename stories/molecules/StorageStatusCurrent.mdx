# StorageStatusCurrent (`molecule/StorageStatus/Current`)

## Uso

Card de uso de armazenamento de **curto prazo**, com botão de comprar mais espaço embutido. Use na página de Armazenamento/Configurações de Plano — no Sidebar, prefira o resumo mais compacto de `StorageStatus`.


**Status: ✅ aligned** — Figma-confirmado nesta US (US-013, releitura
pontual de 2026-08-10), nó `1439:17044`, descrição verbatim: "componente
que possibilita o usuário visualizar espaço utilizado em curto prazo. há
também botão comprar espaço- abre página de pagamento."

**Retomada da 12ª passada ativa (2026-08-13)** — `get_design_context`

`max-w-md` (448px), comprimindo levemente a barra e a linha de valores.

`Default`/`NearLimit`.

## Composição (Figma-confirmado)

"Armazenamento usado: 40GB de 100GB AC" + botão "Comprar espaço" + barra de
progresso + legenda "X%". `"AC"` é uma abreviação literal do Figma (provável
"Acesso rápido") — mantida como prop `scopeAbbr`, sem expandir por extenso
(Regra 9: o texto literal do Figma é `"AC"`, expandir seria inventar).

## Cor da barra — 🔧 divergência do átomo `StorageBar` corrigida em 2026-08-11

Este widget confirma preenchimento **rosa**
(`var(--brand/theme/pink/light,#e8476a)`) para a categoria "Acesso rápido" —
consistente com a Regra 3 (decisão humana 2026-08-10) e com
`molecule/StorageBar` (`Style=Expanded`, já implementado). O átomo
`StorageBar` (`storage-bar.tsx`) na sua variante de barra única
(`tier="quick-access"`) tinha o mesmo tom errado (`brand-pink-dark`,
`#b5254a`) — corrigido nesta auditoria (Regra 11, US-026) para
`brand-pink-light` (`#e8476a`), o mesmo tom Figma-confirmado que este
widget já usava. Este componente continua **sem reutilizar `<StorageBar>`**
— é um widget "irmão" autônomo por composição própria (não por causa da cor,
ver "Relação com `molecule/StorageStatus`" abaixo), com barra local só para
manter a anatomia simples de 1 linha.

## Relação com `molecule/StorageStatus`

Este é um componente **irmão**, não uma variante de
`molecule/StorageStatus` — são 2 frames Figma separados (confirmado via
`get_metadata`, sem relação pai/filho), apesar do nome compartilhado. Ver
`Molecules/StorageStatus.mdx` para o widget maior com seletor de escopo
(Global/Acesso Rápido/Longo Prazo).
