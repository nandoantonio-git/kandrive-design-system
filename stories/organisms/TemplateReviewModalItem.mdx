# TemplateReviewModalItem

Figma: [`organism/TemplateReviewModalItem`](https://www.figma.com/design/2g7udqxWbGA8F9Or7PGNg3/KanDrive-V0.2.1?node-id=1554-21151)

## Uso

Linha da árvore de revisão de [Templates/TemplateReviewModal](../templates/TemplateReviewModal.mdx) — um item por pasta/grupo revisado, com badge de severidade (Duplicado/Fora do padrão/OK, Figma: "Incongruente") e ações "Renomear"/"Editar"/"Excluir".

<Controls of={TemplateReviewModalItemStories.Collapsed} />

## Composição

Botão "Excluir" (linha filha) usa `atom/Button` (`variant="outline"`, migrado de `PushButton isDestructive`) — chrome neutro, só o texto na cor de destrutivo.

## Estados

- **Collapsed** — estado padrão, sem arquivos filhos visíveis
- **Expanded** — revela a linha "Children → Child 1" (Figma-confirmado), com botão "Excluir" próprio por arquivo
- Severidade: `duplicado` (laranja/warning), `incongruente` (neutro), `ok` (neutro + ícone de check)

O estado de expansão é controlado pelo componente pai (`TemplateReviewModal`), repassado via `isExpanded`/`onToggleExpand` — este componente não guarda estado próprio.

| Estado | Tratamento |
| --- | --- |
| Collapsed/Expanded | `isExpanded`/`onToggleExpand` |
| Hover / Pressed / Foco (chevron) | 🧩 com anel de foco; `disabled:pointer-events-none` |
| Foco ("Renomear"/"Editar") | anel `brand-teal-action/50` |
| Hover / Pressed / Foco ("Excluir") | herdados do `atom/Button` |

🧩 = Regra 8: hover/pressed/foco do chevron não desenhados no Figma.
