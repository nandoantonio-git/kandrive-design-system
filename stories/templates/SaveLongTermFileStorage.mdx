# SaveLongTermFileStorage (Figma: `template/SaveLongTermFileStorage/Device=Desktop`, `1439:16907`)

## Uso

Tela de confirmação do fluxo "Guardar em longo prazo" — lista os arquivos selecionados antes de arquivar. Use como etapa final desse fluxo, depois de `ArchiveBrowserModal`. Título "Guardar no longo prazo", com seção "Por que guardar?" e destino "Guardados".

## Composição

| Peça | Origem |
| --- | --- |
| `atom/Icon` (`name="Arquivar"`) | `Atoms/Icon` |
| `atom/Button` (`variant="outline"`/padrão) | `Atoms/Button` — "Cancelar"/"Continuar" (migrado de `PushButton` em 25/09/2026) |
| `molecule/SearchBar/Placeholder/XXL` | `SearchInput` |
| `molecule/ArchiveBrowserModal/ListItem` | `ArchiveBrowserModalListItem` — glifo + nome por linha |

O botão "Adicionar arquivos" e os chips de arquivo selecionado ainda não são componentes próprios documentados — implementados localmente como elementos simples.

### Material

Container usa o material Liquid Glass — ver [Tokens/Materials](../tokens/Materials.mdx).

## Estados

- Lista de arquivos — renderização dinâmica via prop `files`
- Seleção/economia — props `selectedCount`/`savingsLabel`

| Estado | Tratamento |
| --- | --- |
| Linhas de arquivo | só-leitura (instâncias `Selectable=false`); a seleção acontece no `ArchiveBrowserModal` |
| Hover / Pressed / Foco | herdados de `atom/Button`, `SearchInput` e do "Adicionar arquivos" |
