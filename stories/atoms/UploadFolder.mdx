# UploadFolder

🧩 Só código: `molecule/FileItem` não tem variante de upload de pasta (`Type` = Folder, File, Image, Video) e não existe `atom/UploadFolder` no KanDrive V0.2.1. A story aponta para o set `molecule/FileItem`, de onde vem a anatomia.

## Uso

Ícone de upload de uma pasta — glifo composto (contorno de pasta + seta de upload sobreposta), 16×16px. Use em qualquer ação de upload que seja especificamente de uma pasta inteira, não de um arquivo avulso.
