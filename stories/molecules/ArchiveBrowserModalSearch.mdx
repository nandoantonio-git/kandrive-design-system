# ArchiveBrowserModal/Search (Figma: `molecule/ArchiveBrowserModal/Search`, `1485:21074`)

## Uso

Coluna de busca do modal "Adicionar arquivos" — busca + breadcrumb +
painel de arquivos (`molecule/ArchiveBrowserModal/ListItem` repetido). Só
faz sentido dentro de `organism/ArchiveBrowserModal`, não como busca
genérica de tela.

<Canvas of={ArchiveBrowserModalSearchStories.Default} />
<Controls />

## Composição

- Busca: reusa `SearchInput` com placeholder "Buscar arquivos, pastas ou templates"
- Breadcrumb: reusa `Icon` (`ChevronRight`) entre os níveis (ex.: "Pessoal › Fotos › Casamento Ana & Bruno"), com o último item destacado em cor de marca
- Lista: repete `ArchiveBrowserModal/ListItem` dentro de um painel com fundo Liquid Glass

## Estados

Composição estática de exibição — os estados interativos (foco da busca,
seleção de linha) pertencem aos componentes filhos (`SearchInput`,
`ArchiveBrowserModalListItem`), não a este container.
