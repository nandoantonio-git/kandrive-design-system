# ArchiveBrowserModal/ListItem (Figma: `molecule/ArchiveBrowserModalListItem`, `1421:20896`)

## Uso

Linha de arquivo dentro do modal "Adicionar arquivos"
(`organism/ArchiveBrowserModal`) — ícone + nome + metadados. Peça de
composição — não use fora desse modal.

<Canvas of={ArchiveBrowserModalListItemStories.Default} />
<Controls of={ArchiveBrowserModalListItemStories.Default} />

## Anatomia

Ícone de arquivo (asset real exportado do Figma) + nome + metadados
secundários. O ícone reusa a mesma peça visual de `atom/ArchiveItem`,
embora esse átomo em si ainda não exista como componente reutilizável
isolado.

## Estados

<Canvas of={ArchiveBrowserModalListItemStories.Selected} />

- `ArchiveFileRow` — linha padrão, não selecionável
- `ArchiveSelectableRow` — linha selecionada (prop `selected`)

| Estado | Tratamento |
| --- | --- |
| Não selecionada (`Selectable=false`) | Linha padrão |
| Selecionada (`Selectable=true`) | Prop `selected` |
| Hover | Destaque de fundo |
| Pressed | 🧩 `active:opacity-70` |
| Foco | 🧩 Anel de 3px `Brand/Primary/Action` a 50%, só pelo teclado |

Com `onClick`, a linha vira `role="button"` com `tabIndex=0`, Enter/Espaço e `aria-pressed`. Sem `onClick` (lista só de leitura), não é parada de Tab.

## Terminologia

Não renderiza texto fixo de produto — `fileName`/`meta` são conteúdo de
usuário.
