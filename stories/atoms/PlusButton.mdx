# PlusButton (`atom/PlusButton`)

## Uso

Ícone-botão sem chrome de borda pra **ações aditivas** pontuais (ex. adicionar um item a uma lista já em edição) — pra um botão de adicionar mais proeminente/com rótulo, use `ButtonAdd`.


Ícone-botão para ações aditivas — sem chrome de borda, alvo de clique
independente do `PushButton`.
