## Figma (Figma-confirmado)

`get_design_context` no nó `1431:20102` retorna descrição verbatim:
*"botoes do painel de ações disponíveis no modo livre com nodos"*. O
sub-nó `Property 1=Variant8, state=Idle` (`1431:20103`) tem descrição
própria: *"botao de adição de um novo nodo"* — o glifo de adição
(`icon={Plus}`) é o único uso com texto de confirmação Figma explícito;
os demais 3 glifos do toolbar (Expandir/Redefinir/Excluir) são inferidos
por semântica de ícone (🧩 Inferido, Regra 9), já em uso desde
`organism/OrganizeFreeModeCanvas`.

Screenshot do nó mostra 4 glifos × 3 estados (Idle/Hover/Clicked) — 12
instâncias renderizadas lado a lado; o 4º glifo (lixeira) muda para
`brand-feedback-danger-subtle` (`#bc3426` a 35%, mapeado para
`--destructive`) em hover/clicked, os outros 3 usam
`brand-secondary`/`brand-secondary-dark`.

## Fluid interface (Regra 8)

Feedback no press via `motion-safe:active:scale-95`; transições CSS
nativas, interruptíveis. reduced-motion não documentado no Figma —
`motion-safe:` já suprime a animação quando `prefers-reduced-motion`
está ativo (mitigação de engenharia, não confirmação Figma).

## Terminologia

Não renderiza texto visível — `aria-label` por instância ("Adicionar
nodo"/"Expandir"/"Redefinir"/"Excluir"), nenhum termo da lista
proibida/aprovada (Regra 5) se aplica.
