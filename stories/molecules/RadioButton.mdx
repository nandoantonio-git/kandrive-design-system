# RadioButton

Figma: [`molecule/RadioButton`](https://www.figma.com/design/2g7udqxWbGA8F9Or7PGNg3/KanDrive-V0.2.1?node-id=1454-24721)

## Uso

Botão de rádio pra selecionar **1 opção entre um grupo mutuamente
exclusivo**. Pra seleção múltipla/independente, use `Switch` ou o
indicador de seleção de item (`SelectState`), não este componente.

<Controls of={RadioButtonStories.Group} />

## Anatomia

### API

`option: "personal" | "saved"` + `checked`/`onCheckedChange` (controlado,
mesmo padrão de `atom/switch`).

## Estados

<Canvas of={RadioButtonStories.Disabled} />

| Estado | Tratamento |
| --- | --- |
| Unchecked (`Selected=false`) | Círculo vazio, borda neutra |
| Checked (`Selected=true`) | Ponto interno na cor de marca |
| Hover | 🧩 Borda mais escura no não marcado (via `group-hover` do label) |
| Active/Pressed | Feedback imediato no press (`active:scale-90`, com transição) |
| Foco | Anel de 3px `Brand/Primary/Action` a 50%, só pelo teclado |
| Disabled | Extensão de engenharia para uso em formulários reais |

## Terminologia

Os rótulos de exemplo "Pessoal" e "Guardados" representam um filtro de
arquivos genérico, não terminologia de armazenamento restrita.
