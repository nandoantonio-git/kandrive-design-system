# FaqTopicChips

Figma: [`FAQ/Collapsed/Mobile`](https://www.figma.com/design/2g7udqxWbGA8F9Or7PGNg3/KanDrive-V0.2.1?node-id=1670-23381)

✅ Figma KanDrive V0.2.1: `FaqQuickLinks` em `FAQ/Collapsed` e `FAQ/Expanded` Mobile.

## Uso

Os links rápidos do FAQ no mobile: uma faixa horizontal de `atom/Chip` com os tópicos, logo abaixo do título, que rola para o lado. Tocar num chip rola a página até a seção. A partir do desktop, o papel é do `FaqFastLinks` lateral.

## Estados

| Estado | Tratamento |
| --- | --- |
| Ativo / inativo | Chip marcado ao tocar (herda `atom/Chip`) |
| Hover, pressed, foco | Herdados de `atom/Chip` |

## Mobile

É um componente só do mobile: a partir do desktop, o `FaqFastLinks` lateral ocupa o lugar.

## Terminologia

Os rótulos vêm da prop `topics` (sem texto fixo de produto). No FAQ são os tópicos da página ("Primeiros passos", "Longo prazo", "Templates", "Etiquetas", "Duplicados", "Armazenamento", "Problemas comuns"). "Longo prazo" é termo aprovado (Regra 5); nenhum termo proibido aparece.
