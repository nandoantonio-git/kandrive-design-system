# StorageStatusCurrent (`molecule/StorageStatus/Current`)

## Uso

Card de uso de armazenamento de **curto prazo**, com botão de comprar mais
espaço embutido. Use na página de Armazenamento/Configurações de Plano —
no Sidebar, prefira o resumo mais compacto de `StorageStatus`.

<Controls />

## Anatomia

"Armazenamento usado: 40GB de 100GB AC" + botão "Comprar espaço" + barra de
progresso (rosa, categoria "Acesso rápido") + legenda de percentual. `"AC"`
é uma abreviação de "Acesso rápido" que aparece assim no texto original.

Este componente não reutiliza o átomo `StorageBar` — tem sua própria barra
local, para manter a anatomia simples de uma única linha. É um widget
independente de `StorageStatus` (o widget maior com seletor de escopo
Global/Acesso Rápido/Longo Prazo), não uma variante dele.

## Estados

| Estado | Nota |
| --- | --- |
| Default | Valores/percentual via props |
| Hover (botão) | — |
| Active/Pressed (botão) | Feedback de escala no clique |
| Near-limit/Empty | Não implementado — sem especificação visual confirmada para esses casos |

## Terminologia

"Comprar espaço" é o rótulo do botão de ação.

## Tipografia

Botão e legenda usam microtexto (10px) — o valor numérico principal
("40GB de 100GB") já está em tamanho de leitura primária (20px), então
o texto menor nunca é o único portador da informação.
