# FolderItem (Figma: `atom/FolderItem`, `1440:24306`)

## Uso

Linha/card compacto pra representar **uma pasta** dentro de uma lista de arquivos — mesma anatomia de `ArchiveItem`/`ImageItem`/`VideoItem`, com os mesmos 5 estados de seleção/interação.

## Estados

`Idle` · `Hover` · `Pressed` · `Disabled` · `Selected` · `Selected-Hover` · `Selected-Pressed`. Sem loading/error — é um glifo de item estático.
