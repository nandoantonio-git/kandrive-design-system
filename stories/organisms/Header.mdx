# Header (Figma: `organism/Header`, `1255:22352`)

## Uso

Cabeçalho fixo do topo — 3 variantes por página (`Navbar`/`settings`/`storage`). Só `Navbar` expõe as ações de fluxo ao vivo (Organizar/Guardar); use `settings`/`storage` nas páginas correspondentes, sem essas ações.

## Composição

| Peça | Origem |
| --- | --- |
| `molecule/input-search` | `Molecules/SearchInput` |
| `atom/Button` (padrão, `primary`) | `Atoms/Button` (migrado de `PushButton` em 25/09/2026) |
| `molecule/action-pill` | `Molecules/ActionPill` — composição real Help/Settings/Conta |

"Organizar" e "Guardar" usam `atom/Button` (padrão, `primary`) — nenhum componente de botão separado. "Guardar" é termo aprovado.

### Material

O `action-pill` embutido usa o material Liquid Glass — ver [ActionPill](../molecules/ActionPill.mdx)/[Tokens/Materials](../tokens/Materials.mdx); o `Header` em si (fundo sólido) não usa o material.

## Estados

Herdados dos sub-componentes (`SearchInput`, `Button`, `ActionPill`) — nenhum estado próprio do container, exceto o avatar do mobile.

| Estado | Tratamento |
| --- | --- |
| Hover / Pressed / Foco | herdados de `SearchInput`, `Button` e `ActionPill` |
| Hover (avatar, mobile) | 🧩 opacidade |
| Pressed (avatar, mobile) | 🧩 `motion-safe:active:scale-95` |

🧩 = Regra 8: hover/pressed do avatar (mobile) não desenhados no Figma.

🧩 O logo (tablet e desktop) é um link para o início (`homeHref`, padrão `/`; `onLogoClick` para navegar por rota do app), com o rótulo "Kandrive, ir para o início" e o anel de foco padrão. Pedido do usuário em 2026-09-29; no Figma, o protótipo liga o logo de cada tela à Home do mesmo aparelho.

## Terminologia

"Guardar" é termo aprovado. "Organizar" também consta da lista aprovada da Regra 5 (adicionado em 2026-08-23) — texto literal Figma-confirmado, consistente com o domínio do produto.
