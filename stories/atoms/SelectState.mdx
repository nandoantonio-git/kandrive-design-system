# SelectState (Figma: `atom/SelectState`, `212:3726`)

## Uso

Indicador de seleção — um círculo pequeno com um check dentro. É um sub-componente, composto no canto inferior direito de `ArchiveItem`, `FolderItem`, `ImageItem` e `VideoItem` para marcar item selecionado (`selected`/`selected-hover`/`selected-pressed`). Não é usado sozinho numa tela.

## Anatomia

Círculo de 8px com um glifo de check centralizado por dentro, dimensionado para caber com uma folga mínima em vez de ultrapassar a borda do círculo. Dois eixos: `theme` (Light/Dark) × `state` (Default/Hover/Pressed).

## Estados

`default` · `hover` · `pressed` — combinados com `theme="light"` ou `theme="dark"`. Não é interativo por si: o estado é repassado pelo item que o contém.

| Estado | Tratamento |
| --- | --- |
| Hover | Prop `state="hover"` (Figma `State=Hover`), vinda do item pai |
| Pressed | Prop `state="pressed"` (Figma `State=Pressed`), vinda do item pai |
