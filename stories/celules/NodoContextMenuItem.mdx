# NodoContextMenuItem (Figma: `celule/nodoContextMenuItem`, `1421:20528`)

## Uso

Pílula seletora (dropdown ou valor estático) usada nas linhas de
condição/filtro do `molecule/nodoContextMenu`. Peça de composição — não use
fora desse menu de contexto do nodo.

## Tipos (`kind`)

`attribute`, `condition`, `value`, `date`, `interval` — combináveis com
`hasChevron`, `expanded`, `selectedOption`, `value` e `error`.

Seleção de data normalmente usaria um componente de calendário próprio (do
navegador ou de uma biblioteca externa) — isso não faz parte deste
componente, que cobre só a pílula seletora.

## Estados

- Placeholder — fechado, sem valor
- Filled — fechado, com valor
- Expanded — aberto, lista de opções (`options`)
- Selected option — opção marcada dentro da lista
- Error — borda/anel de erro (prop `error`)
- Disabled

## Terminologia

Textos como "Atributo", "Operação", "Valor...", "Data", "Intervalo" e as
opções ("Tamanho", "Maior que", "Durante", "Antes", "Depois" etc.) fazem
parte do vocabulário de construção de filtro do produto.
