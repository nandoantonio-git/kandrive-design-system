# StorageStatus (`molecule/StorageStatus`)

## Uso

Widget de status de armazenamento (totais por tier) — usado no **Sidebar**
pra dar visão geral rápida de uso. Pra a página completa de Armazenamento,
com detalhe de curto prazo, use `StorageStatusCurrent` + `StorageBar`
diretamente.

<Controls />

## Variante `Expanded` — seletor de escopo

Tem 3 painéis (`Global`/`Corrente`/`Longo Prazo`) que funcionam como um
seletor: o painel ativo mostra um chip preenchido com a cor da categoria,
os outros 2 aparecem como chips outline clicáveis para trocar de painel.
O botão "Liberar espaço" só aparece no painel `Global` — termo aprovado
para esta página (Armazenamento) — e abre o modal de limpeza de espaço.

No painel `Global`, a barra é segmentada por tipo de arquivo, com legenda
(Imagens/Documentos/Vídeos/Outros) logo abaixo usando as mesmas cores dos
segmentos. Nos painéis `Corrente` e `Longo Prazo`, aparece uma legenda de
2 itens abaixo da barra: "XX em uso" e "XX Livre".

## Variante `Sidebar` — versão compacta

Mostra só 1 tag ("Longo Prazo") + barra + texto de uso. Não expõe o
seletor de escopo nem botões de ação.

## Estados

| Estado | Nota |
| --- | --- |
| `scope` (`global`/`current`/`long-term`) | Alterna entre os 3 painéis da variante Expanded |
| `variant="sidebar"` | Versão compacta |
| Hover/Active (chips, botões) | Herdados dos componentes filhos |

Os estados `NearLimit`/`LimitReached`/`Empty` mencionados na descrição do
componente não estão implementados — sem especificação visual confirmada
para eles.

## Terminologia

"Liberar espaço" é aprovado no contexto desta página (Armazenamento).
"Comprar espaço" também aparece como rótulo de botão. Nenhum termo
proibido é usado.
