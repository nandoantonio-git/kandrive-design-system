# StorageSidebar

Figma: [`organism/StorageSidebar`](https://www.figma.com/design/2g7udqxWbGA8F9Or7PGNg3/KanDrive-V0.2.1?node-id=635-5608)

## Uso

Widget de status de armazenamento embutido na Sidebar, com atalhos pra gerir espaço/upgrade de plano. Use como versão compacta pra navegação lateral — pra a página completa de Armazenamento use `StorageStatusCurrent`.

## Terminologia

Este componente usa "Acesso rápido"/"Longo prazo" (termos aprovados) pra as tags de tier. O botão de gestão de espaço é "Gerir espaço" (leva à página Status de armazenamento, Figma: "botões para página de gerir espaço"). O "Liberar espaço" é outro botão, da própria página de status.

O tag "Corrente" (nome usado em outra variante do mesmo widget no Figma) não consta na lista de termos aprovados nem é termo proibido.
