# ArchiveBrowserModal/ListItem (Figma: `molecule/ArchiveBrowserModal/ListItem`, `1421:20896`)

## Uso

Linha de arquivo dentro do modal "Adicionar arquivos"
(`organism/ArchiveBrowserModal`) — ícone + nome + metadados. Peça de
composição — não use fora desse modal.

## Anatomia

Ícone de arquivo (asset real exportado do Figma) + nome + metadados
secundários. O ícone reusa a mesma peça visual de `atom/ArchiveItem`,
embora esse átomo em si ainda não exista como componente reutilizável
isolado.

## Estados

- `ArchiveFileRow` — linha padrão, não selecionável
- `ArchiveSelectableRow` — linha selecionada (prop `selected`)

## Terminologia

Não renderiza texto fixo de produto — `fileName`/`meta` são conteúdo de
usuário.
