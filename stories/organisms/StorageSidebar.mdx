# StorageSidebar (`organism/storage-sidebar`)

## Uso

Widget de status de armazenamento embutido na Sidebar, com atalhos pra gerir espaço/upgrade de plano. Use como versão compacta pra navegação lateral — pra a página completa de Armazenamento use `StorageStatusCurrent`.

## Terminologia

Este componente usa "Acesso rápido"/"Longo prazo" (termos aprovados) pra as tags de tier. O botão de gestão de espaço tem 2 rótulos por contexto: "Liberar Espaço" é o default deste componente (página de Armazenamento/Config. de Plano); "Gerir Espaço" é usado quando `organism/Sidebar` sobrescreve o prop `manageSpaceLabel` ao compor este widget no painel lateral persistente.

O rótulo do segundo botão, "Comprar Espaço", e o tag "Corrente" (nome usado em outra variante do mesmo widget no Figma) não constam formalmente na lista de termos aprovados nem são termos proibidos.

## Estados

- Expanded/Collapsed — prop `expanded`, delega a `SidebarToggle`
- Hover/Active dos botões — herdado do `PushButton`
