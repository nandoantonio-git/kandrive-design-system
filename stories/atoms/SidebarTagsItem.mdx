# SidebarTagsItem

Figma: [`atom/SidebarTagsItem`](https://www.figma.com/design/2g7udqxWbGA8F9Or7PGNg3/KanDrive-V0.2.1?node-id=1421-20907)

## Uso

Linha de etiqueta dentro da lista de tags da Sidebar — usada quando o usuário já tem etiquetas criadas e precisa navegar/filtrar por elas no painel lateral. Ponto de cor (`brand-teal`) + nome da etiqueta.

## Estados

`idle` (sem fundo) · `hover` (fundo sutil) · `selected` (fundo escuro)

| Estado | Tratamento |
| --- | --- |
| Hover | Fundo sutil (Figma `State=Hover`) |
| Pressed | Fundo escuro do Figma `State=Pressed`, no `:active` real |
| Selected | Mesmo fundo do Pressed, fixo; `aria-pressed` |
| Foco 🧩 | Anel `ring-3 brand-teal-action/50`, só pelo teclado (Regra 8) |
| Disabled 🧩 | 50% de opacidade, sem ponteiro (Regra 8) |
| Transição | Troca de fundo animada |
