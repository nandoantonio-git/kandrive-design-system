# SearchInput

Figma: [`molecule/SearchInput`](https://www.figma.com/design/2g7udqxWbGA8F9Or7PGNg3/KanDrive-V0.2.1?node-id=3010-6061)

## Uso

Campo de busca — input de texto com ícone de lupa, usado para
buscar arquivos/pastas/templates. Use `state="success"`/`"danger"` quando
precisar dar feedback de validação persistente (anel de cor fixo) —
diferente do anel de foco padrão, que é só feedback de interação.

## Estados

<Canvas of={SearchInputStories.Success} />
<Canvas of={SearchInputStories.Danger} />

| Estado | Tratamento |
| --- | --- |
| Default | Borda e fundo neutros |
| Hover | 🧩 Fundo levemente mais escuro no campo |
| Focus (`State=Focus`) | Anel de 3px `Brand/Primary/Action` a 50% |
| Com valor (`Filled=true`) | Suportado nativamente via `value`/`defaultValue` |
| Disabled (`State=Disabled`) | Opacidade reduzida, não aceita digitação |
| Loading | Spinner no lugar do ícone de busca |
| Erro (`Status=Error`, `aria-invalid`) | Anel `destructive` |
| `state="success"` | Anel persistente verde — feedback de validação positiva |
| `state="danger"` | Anel persistente vermelho — feedback de validação de erro |

🧩 Regra 8: hover do campo não desenhado no Figma.
