# DropdownSelectLabel (Figma: `molecule/DropdownSelect/Label`, `1439:19650`)

## Uso

Dropdown "Etiquetar" — segundo tipo de dropdown do canvas, diferente de
[`DropdownSelectGroupBy`](./DropdownSelectGroupBy.mdx). Estruturalmente
quase idêntico a `molecule/Label` — use este quando o contexto for
especificamente o canvas de organização, `molecule/Label` nos demais
fluxos de etiquetagem.

<Canvas of={DropdownSelectLabelStories.Default} />
<Controls />

## Anatomia

Rótulo de seção "ETIQUETAR" + botão "Etiquetar" com ícone de etiqueta e
chevron. Quando expandido, mostra a lista de etiquetas disponíveis,
incluindo a opção "+ Nova Etiqueta" (renderizada pelo componente
[`DropdownSelectLabelItem`](../atoms/DropdownSelectLabelItem.mdx)).

<Canvas of={DropdownSelectLabelStories.Expanded} />
<Canvas of={DropdownSelectLabelStories.Disabled} />

## Estados

- `default` — fechado
- `expanded` — aberto, mostrando a lista de etiquetas
- `disabled` — desabilitado

Não há estado de hover próprio documentado neste componente.

## Terminologia

"ETIQUETAR"/"Etiquetar" são vocabulário de rotulagem de arquivo, sem
restrições de terminologia aplicáveis.
