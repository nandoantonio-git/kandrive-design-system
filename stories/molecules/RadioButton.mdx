# RadioButton (`molecule/radioButton`)

## Uso

Botão de rádio pra selecionar **1 opção entre um grupo mutuamente
exclusivo**. Pra seleção múltipla/independente, use `Switch` ou o
indicador de seleção de item (`SelectState`), não este componente.

<Canvas of={RadioButtonStories.Group} />
<Controls />

## API

`option: "personal" | "saved"` + `checked`/`onCheckedChange` (controlado,
mesmo padrão de `atom/switch`).

## Estados

| Estado | Nota |
| --- | --- |
| Unchecked | Círculo vazio, borda neutra |
| Checked | Ponto interno na cor de marca |
| Hover | — |
| Active/Pressed | Feedback imediato no press |
| Disabled | Extensão de engenharia para uso em formulários reais |

## Terminologia

Os rótulos de exemplo "Pessoal" e "Guardados" representam um filtro de
arquivos genérico, não terminologia de armazenamento restrita.
