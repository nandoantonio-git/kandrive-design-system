# Label (Figma: `molecule/Label`, `1421:18687`)

## Uso

Pílula de dropdown de etiquetas. Use nos fluxos gerais de etiquetagem de
arquivo; dentro do canvas de organização, o equivalente é
`DropdownSelectLabel`.

## Anatomia

Legenda "ETIQUETAR" + pílula com ícone de etiqueta, fundo Liquid Glass e
chevron. Quando expandida, mostra um campo de busca mini, uma lista de
badges por tipo de arquivo (Documentos/Imagens/Vídeos) e um item "+ Nova
Etiqueta".

## Componente semelhante

`molecule/Label` e `DropdownSelectLabel` são visualmente muito parecidos
(mesma legenda, mesma composição base) mas são dois componentes Figma
distintos com pequenas diferenças: o chevron deste usa um glifo próprio
(caret), enquanto `DropdownSelectLabel` usa uma seta triangular; e este
tem os estados `Expanded`/`Disabled` confirmados de forma mais completa
(busca + badges por tipo).

## Estados

- `default` — fechado
- `expanded` — aberto, mostrando busca e lista de etiquetas
- `disabled`

## Terminologia

"Etiquetar"/"ETIQUETAR" são vocabulário de rotulagem de arquivo, sem
restrições de terminologia aplicáveis.
