# UploadPopover (`organism/upload-popover`)

## Uso

Popover de progresso de upload, fixo no canto inferior esquerdo. Aparece automaticamente durante uploads em andamento — não é acionado manualmente pelo usuário.

## ⚠️ Gap de terminologia — Regra 9, urgência baixa (ver `docs/conflicts.md`)

O texto Figma-confirmado deste nó está **100% em inglês** ("Uploading 3
files", "6 seconds left", "IN PROGRESS", "62% • 18MB OF 29MB") —
inconsistente com o restante da página (português). Este componente usa a
tradução direta ("Enviando N arquivos", "N segundos restantes", "Em
andamento"), nunca o texto literal do Figma — nunca apresentar uma
tradução própria como se fosse o texto Figma-confirmado (Regra 9).

## Composição

Peça isolada — não compõe outros atoms/molecules documentados desta
reconciliação.

## Conflito de variantes (Regra 1)

Botões de pausa/fechar são ícones sem chrome de botão — não são
`PushButton`, não fragmentam a Regra 1.

## Estados e fluid interface (Regra 8)

| Estado | Implementado |
| --- | --- |
| Em andamento | ✅ prop `percent`, barra de progresso animável (`transition-[width]`) |
| Concluído (por arquivo) | ✅ prop `files[].done`, ícone `CheckCircle2` |
| Disabled/Error | Não documentado no Figma — não implementado |

**reduced-motion**: não documentado no Figma; a barra de progresso muda de
`width` via CSS transition nativa (interruptível, parte do valor atual).
