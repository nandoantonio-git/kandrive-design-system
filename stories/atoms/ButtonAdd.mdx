## Reconciliação (US-016)

`organism/SaveLongTermFileStorage` já renderizava "Adicionar arquivos" com
markup de `<button>` inline duplicando esta anatomia (borda + ícone `+` +
label teal) — corrigido para consumir `ButtonAdd`. `molecule/nodoContextMenu`
(novo nesta US) usa o mesmo átomo para "Adicionar Regra".

## Material Liquid Glass

o material completo de 2 camadas usado em painéis maiores.

## Fluid interface (Regra 8)

Transições de cor via `transition-colors` nativas, interruptíveis.
reduced-motion não documentado no Figma — não aplicável (sem animação de
movimento, só cor).

## Terminologia

Label é prop (`label`/`children`) — cada uso passa cópia real ("Adicionar
arquivos"/"Adicionar Regra"), nunca o placeholder genérico "Label" do
Figma. Nenhum termo da lista proibida (Regra 5) se aplica.

## Fidelidade code-level

Glifo `Plus` (`lucide-react`, 12px) — correspondência direta com o ícone
`plus` do Figma. Rótulo compacto (`text-xs`, 12px) segue a mesma decisão
humana já documentada em `docs/conflicts.md` para botões `h-8` (Regra 4).
