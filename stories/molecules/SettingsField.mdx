# SettingsField

Figma: [`molecule/TextField`](https://www.figma.com/design/2g7udqxWbGA8F9Or7PGNg3/KanDrive-V0.2.1?node-id=3029-3843)

✅ Figma-confirmado: é o `molecule/TextField` (`3029:3843`), usado nas linhas de campo do `organism/SettingsCard`.

## Uso

Par rótulo + campo de texto dos formulários de Settings (cards "Conta", "Senha" e "Excluir conta") e do checkout em Payment. Nenhum átomo de input genérico existia no catálogo — `molecule/SearchBar` é específico de busca (ícone de lupa, pílula). Extraído como molecule único (Regra 1/10) em vez de repetido em cada card.

## Anatomia

- Rótulo em 13px medium, ligado ao campo (`<label htmlFor>` com id gerado).
- Campo de 36px, raio 6, borda `#d4d4d4` (Dark: `#52525b`), fundo `Effect/Glass/White` a 70%, texto 14px.
- Aceita as props nativas de `<input>` (`type`, `placeholder`, `value`…), menos `id`.

## Terminologia

O rótulo é conteúdo de cada formulário ("Nome", "E-mail", "Senha atual", "Nova senha", "Confirmar nova senha", "Confirme sua senha para continuar", "Nome no cartão", "E-mail para recibo"…). Nenhum termo proibido (Regra 5).
