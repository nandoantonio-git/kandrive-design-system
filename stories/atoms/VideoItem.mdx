# VideoItem

Figma: [`molecule/FileItem`](https://www.figma.com/design/2g7udqxWbGA8F9Or7PGNg3/KanDrive-V0.2.1?node-id=1442-7859)

## Uso

Linha/card compacto para representar um vídeo dentro de uma lista de arquivos — mesma anatomia de `ArchiveItem`/`FolderItem`/`ImageItem`. A variante `favicon-header-thumbnail` omite o controle de seleção de propósito (contexto de thumbnail, não de lista selecionável). No Figma é o `Type=Video` do set `molecule/FileItem`.

## Estados

`idle` · `hover` · `pressed` · `disabled` · `selected` · `selected-hover` · `selected-pressed` · `favicon-header-thumbnail`

| Estado | Tratamento |
| --- | --- |
| Hover | Glifo de hover do Figma (`State=Hover`) |
| Pressed | Glifo de pressed do Figma (`State=Pressed`) |
| Selected / Selected-Hover / Selected-Pressed | Glifo do estado + `atom/SelectState` no canto |
| Foco 🧩 | Anel `ring-3 brand-teal-action/50`, só pelo teclado (Regra 8) |
| Disabled | Glifo de disabled do Figma (`State=Disabled`), `aria-disabled` |
| Transição | Sem transição CSS: os estados trocam o SVG (`src`), o que não é animável |

### Interação

Sem `state` fixo — passe o mouse, clique/pressione Enter pra selecionar de verdade (não é freeze-frame). `state` continua disponível como override pra congelar um estado específico (é o único jeito de chegar em `favicon-header-thumbnail`, que não faz parte do ciclo real de interação).
