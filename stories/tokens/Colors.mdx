# Cores

Todos os tokens de cor do código, com **Light e Dark lado a lado**. Os valores são lidos **ao vivo** de `src/index.css` (regras `:root` e `.dark`), então esta página nunca fica desatualizada em relação ao que os componentes renderizam. Cada token é comparado com a variável correspondente do Figma **KanDrive V0.2.1** (coleção Core, quadro *Foundation/Color Modes*).

## Legenda

| Marca | Significado |
| --- | --- |
| ✅ Figma-confirmado | O token tem uma variável no Figma, e os valores Light e Dark são iguais |
| ⚠️ Diverge do Figma | O token tem uma variável no Figma, mas algum valor é diferente. O valor do Figma aparece embaixo. |
| 🧩 Só no código | Não existe variável no Figma. Em geral é a base do shadcn/ui. |

## Como ler os papéis

- **Texto × superfície.** No Dark, a primária muda de papel conforme o uso:
  - `--brand-teal` (`Brand/Primary/Default`) é para **texto e ícone**, e fica quase branco no Dark;
  - `--brand-teal-action` (`Brand/Primary/Action`) é para **fundo de botão**, e continua `#007e96` com texto branco, que passa no WCAG;
  - os tokens `*-surface` seguem a mesma lógica para perigo, sucesso, alerta e a primária escura.
- **Categorias de armazenamento** (Regra 3 e Regra 6):
  - **rosa** = Acesso rápido (`--storage-fast-access-surface`, `--brand-pink-*`);
  - **azul** = Longo prazo (`--storage-long-term-surface`);
  - as duas cores valem nos dois modos.
- **Dark só com a paleta da marca.** Os tons do Dark vêm da página *Design Language* do Figma. Os teais são `#007E96`, `#2391AA`, `#337084`, `#1A5E6E` e `#C8DCE3`. Quando o Dark precisa de um tint, usa um desses com opacidade, sem inventar um tom novo.
- **Nomes.** Os nomes CSS vêm do histórico do código (`--brand-teal`…). A coluna Figma mostra o nome da variável do Figma (Regra 2).

Para usar em um componente, clique no nome do token para copiar `var(--…)`. Pela classe do Tailwind, os mesmos tokens estão expostos em `@theme inline` (por exemplo `bg-brand-teal-action`, `text-brand-teal`).

## Logo

As cores do logo (`Logo/*` no Figma) não são tokens CSS, porque ficam dentro dos SVGs `src/assets/logo/kandrive-logo.svg` e `kandrive-logo-dark.svg`. O símbolo é o **Kan, o canguru**. Veja a página **Introdução** e a nota `docs/vault/Design System/Logo.md`.
