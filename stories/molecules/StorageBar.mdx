# StorageBar (Figma: `molecule/StorageBar`, `1421:17904`)

## Uso

Barra de progresso de uso de armazenamento, uma por tier. Use a variante
`Expanded` (segmentada por tipo de arquivo, incluindo a cor "Acesso
rápido") quando precisar detalhar composição, não só total usado.

<Controls />

## Props

- `tier="quick-access"` — barra rosa, uso de curto prazo
- `tier="long-term"` — barra teal escuro, uso de longo prazo
- `value` — 0–100, preenchimento proporcional

## Variante segmentada (`StorageBarExpanded`)

<Canvas of={StorageBarStories.Expanded} />

Componente separado (`StorageBarExpanded`, prop `segments: { tier, value }[]`)
que mostra N segmentos lado a lado em vez de um preenchimento único —
usa 2 tons de teal (categoria "Longo prazo") e 2 tons de rosa (categoria
"Acesso rápido"). O rosa é a cor semântica oficial da categoria "Acesso
rápido" no design system.

## Estados

`StorageBar` é um elemento de exibição estática (`role="progressbar"`),
não interativo — não recebe foco, clique ou input do usuário. O
preenchimento anima suavemente quando `value` muda.

## Terminologia

Não renderiza texto próprio — o rótulo do tier (ex.: "Acesso rápido") é
responsabilidade do componente/tela que a envolve.
