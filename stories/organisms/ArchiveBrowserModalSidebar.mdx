## Composição

Não é a `Sidebar` completa reaproveitada — é uma composição própria, menor, confirmada no nó do modal (Regra 9: não presumir reuso 1:1 sem confirmação). "Etiquetas" usa `atom/badge/TypeLabel` (`FileTypeLabel`).

## Estados

| Estado | Tratamento |
| --- | --- |
| Item ativo | opacidade total; inativos a 50% |
| Hover | 🧩 inativo vai de 50% a 100% de opacidade, com transição |
| Pressed | 🧩 feedback de pressão no item |
| Foco | 🧩 anel de foco visível (`focus-visible`) |

🧩 = Regra 8: hover/pressed/foco dos itens não desenhados no Figma.
