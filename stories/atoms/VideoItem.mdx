# VideoItem (Figma: `atom /VideoItem`, `1442:7858`)

## Uso

Linha/card compacto para representar um vídeo dentro de uma lista de arquivos — mesma anatomia de `ArchiveItem`/`FolderItem`/`ImageItem`. A variante `favicon-header-thumbnail` omite o controle de seleção de propósito (contexto de thumbnail, não de lista selecionável).
