# ViewModeToggle

Figma: [`molecule/ViewModeToggle`](https://www.figma.com/design/2g7udqxWbGA8F9Or7PGNg3/KanDrive-V0.2.1?node-id=622-3468)

## Uso

Pílula de alternância do modo de visualização do grid de arquivos
(Grade/Lista/Colunas). Use no cabeçalho de qualquer tela com listagem de
arquivos que suporte mais de um layout — se a tela só tem um layout
possível, não adicione o toggle.

## Anatomia

Rótulo de seção "VISUALIZAR" + 3 botões (Grade/Lista/Colunas), cada um com
ícone + label, sobre fundo Liquid Glass. O botão do modo ativo tem
destaque de fundo e cor de texto de marca.

## Estados

| Estado | Tratamento |
| --- | --- |
| Selecionado | Fundo escuro + texto na cor de marca clara |
| Não selecionado | Texto neutro |
| Hover | Leve destaque de fundo (`zinc-600` a 10%) |
| Pressed | 🧩 `active:opacity-70` |
| Foco | 🧩 Anel de 3px `Brand/Primary/Action` a 50%, só pelo teclado |
| Disabled | Não implementado |

## Mobile

<Canvas of={ViewModeToggleStories.Compact} />

`size="compact"` (73×31, só ícones, sem o rótulo "VISUALIZAR") exclui
"Colunas" automaticamente — Colunas é exclusivo de tablet/desktop. Não precisa passar `modes` pra isso; é o comportamento
padrão do componente. Use `modes` só pra um recorte
diferente do padrão.

## Terminologia

🧩 Rótulos traduzidos na revisão de UX writing: "Grade"/"Lista"/
"Colunas" (Figma: "Grid"/"List"/"Columns") — a mistura de inglês e
português do conteúdo original foi eliminada. "VISUALIZAR" é texto
Figma-confirmado, mantido literal.
