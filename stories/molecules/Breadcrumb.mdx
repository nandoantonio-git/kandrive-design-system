# Breadcrumb (Figma: sem node confirmado)

O JSDoc cita `Navigation - Breadcrumb` (`1421:19875`), que não resolve no KanDrive V0.2.1. As telas do V0.2.1 usam instâncias de `molecule/Breadcrumb` (ex.: `1745:13477` em `Settings/Appearance/Desktop`), mas o componente principal ainda não foi confirmado.

## Uso

Trilha de navegação no topo do conteúdo principal das páginas (Home, Armazenamento, Configurações, Planos, FAQ, Templates de organização). Some no mobile: nas páginas, entra com `hidden tablet:flex`.
