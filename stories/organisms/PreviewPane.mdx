# PreviewPane

Figma: [`organism/PreviewPane`](https://www.figma.com/design/2g7udqxWbGA8F9Or7PGNg3/KanDrive-V0.2.1?node-id=724-3597)

## Uso

Painel de detalhe de um arquivo selecionado — metadados + ações (Salvar, Compartilhar). Só aparece no layout de visualização em coluna, ao lado de `FileListContainer`.

<Controls of={PreviewPaneStories.Default} />

## Composição

Compõe `molecule/thumbnail-large` pra pré-visualização do arquivo selecionado. Grid de metadados: "Proprietário", "Criado", "Formato" (texto puro, sem badge), "Tamanho", "Localização".

A seção "Etiquetas" mostra 2 estilos de pílula: uma neutra (borda + fundo cinza claro) e uma vermelha preenchida para tags de destaque (ex.: "Urgente"). A prop `tags` aceita `string | { label: string; danger?: boolean }` — tags `danger` usam a pílula vermelha, as demais a pílula neutra.

"Salvar"/"Compartilhar" são botões simples com ícone + label, sem chrome preenchido — não usam `atom/Button` (que tem um tratamento visual diferente, chrome preenchido/outline, reservado a ações primárias/secundárias de fluxo).

### Material

Container usa o material Liquid Glass — ver [Tokens/Materials](../tokens/Materials.mdx).

## Estados

- Default
- Seção "Etiquetas" omitida quando não há tags

| Estado | Tratamento |
| --- | --- |
| Expanded (painel aberto) | eixo `Expanded` do Figma |
| Sem tags | seção "Etiquetas" omitida |
| Hover ("Salvar"/"Compartilhar") | com transição |
| Pressed ("Salvar"/"Compartilhar") | 🧩 `active:` |
| Foco ("Salvar"/"Compartilhar") | 🧩 anel de foco visível |

🧩 = Regra 8: pressed e foco de "Salvar"/"Compartilhar" não desenhados no Figma.
