# FreeModeOutputNode

Figma: [`molecule/FreeModeOutputNode`](https://www.figma.com/design/2g7udqxWbGA8F9Or7PGNg3/KanDrive-V0.2.1?node-id=1421-20262)

## Uso

Nó de destino final do canvas Modo Livre — para onde os arquivos filtrados
são organizados. Último nó da cadeia visual: sempre 1 por composição do
canvas, nunca múltiplos na mesma tela.

## Anatomia

### Variantes

<Canvas of={FreeModeOutputNodeStories.Compact} />

- `default` — mostra as estatísticas (arquivos incluídos, tamanho
  estimado, regras aplicadas) e a prévia de arquivos
- `compact` — estado placeholder vazio, antes de conectar uma pasta de
  destino; o conteúdo é cortado por uma altura reduzida

A caixa do ícone usa um tom de teal mais escuro (`#176a78`) que o restante
do canvas — cor intencional deste nó, não um desvio a corrigir.

### Ícones

Reaproveita os mesmos ícones da variante `resultado` de
[`celule/FreeModeItemNode`](./FreeModeItemNode.mdx).

## Estados

O nó em si é estático; a única parte interativa é o botão "Prévia de arquivos", que expande a lista.

| Estado | Tratamento |
| --- | --- |
| Expandido (`Expanded=true`) / recolhido (`Expanded=false`) | Variante `default` / `compact` |
| Prévia aberta / fechada | "Prévia de arquivos" com `aria-expanded` |
| Hover | 🧩 Opacidade reduzida em "Prévia de arquivos" |
| Pressed | 🧩 Opacidade reduzida no `:active` |
| Foco | 🧩 Anel de 3px `Brand/Primary/Action` a 50%, só pelo teclado |

## Terminologia

"Resultado", "Arquivos incluídos", "Tamanho estimado", "Regras
aplicadas", "Prévia de arquivos", "Nome pasta output" são os textos reais
usados no produto.
