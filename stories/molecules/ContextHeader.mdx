# ContextHeader (Figma: `molecule/context-header`, `1421:19589`)

## Uso

Header de contexto que dá feedback de quantos itens estão sendo
selecionados. Use sempre que uma seleção em lote estiver ativa numa
lista/grid — desaparece quando a seleção é limpa.

<Canvas of={ContextHeaderStories.Default} />
<Controls />

## Anatomia

Botão de limpar seleção + contador de itens ("X itens selecionado") +
divisor vertical + 5 ações: compartilhar, baixar, mover, excluir e mais
opções (menu).

## Estados

- `expanded` (padrão)
- `collapsed` (altura/opacidade reduzidas, usado ao recolher o header)

<Canvas of={ContextHeaderStories.Collapsed} />

## Terminologia

O rótulo do contador ("X itens selecionado") é texto Figma literal —
inclui a concordância no singular mesmo com contagem plural, preservada
propositalmente por fidelidade ao texto original.

Nota de tipografia: este componente usa Figtree em vez de Manrope, que é
o que o arquivo Figma original especifica — ver `docs/conflicts.md` para
o histórico dessa decisão (Figtree é a família única do design system).
