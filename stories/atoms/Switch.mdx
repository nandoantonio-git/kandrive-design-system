# Switch (`atom/switch`)

## Uso

Interruptor liga/desliga genérico — usado sempre que uma configuração binária precisa de um toggle imediato (sem confirmação), diferente de um checkbox de seleção em lista.

## Variantes (Figma-confirmado)

2 variantes: `State=off` (`1454:20955`) e `State=on` (`1454:20965`). Track
36×20px, thumb 16×16px deslizando 18px ao ligar. `On` usa preenchimento
`#007e96` (`brand-teal`); `Off` usa o cinza literal `#d9d9d9`
Figma-confirmado neste node.

## API

Prop `checked` (controlado) + `onCheckedChange`, em vez de replicar `State`
como enum de string — mais idiomático para um controle binário real em
React/HTML (`role="switch"`, `aria-checked`), sem perder fidelidade visual
das 2 variantes Figma.

## Estados (Regra 8)

| Estado | Aplicável? | Nota |
| --- | --- | --- |
| Default (off) | ✅ | Track cinza, thumb à esquerda |

| Error | ❌ Não aplicável | Não é um campo validável |

## Fluid interface (Regra 8)

Transição de posição do thumb (`translate-x`) e cor do track são
interruptíveis (`transition-colors`/`transition-transform` padrão do
navegador, sem animação customizada bloqueante) — soltar o clique no meio da
transição não trava o controle. **reduced-motion: não documentado no
Figma** — nenhuma variante ou nota de `prefers-reduced-motion` foi
encontrada no nó consultado; a transição usa `motion-safe:` para já
respeitar a preferência do usuário no nível de engenharia, sem que isso seja
uma confirmação Figma.
