# DropListItem (Figma: `molecule/DropListItem`, `1440:23803`)

## Uso

Item de lista suspensa (ícone + rótulo) usado dentro do
`organism/dropList`. Peça de composição — use dentro de `DropdownMenu`,
nunca isolado numa tela. O item ocupa a largura total do menu que o
contém.

## Estados

<Canvas of={DropListItemStories.Hover} />
<Canvas of={DropListItemStories.Active} />

- `idle`
- `hover` — fundo cinza claro
- `pressed` — fundo escuro semitransparente (Figma chama esse eixo de `Clicked`; normalizado no código pra bater com o resto do catálogo)

| Estado | Tratamento |
| --- | --- |
| Default (`State=Default`) | Transparente |
| Hover (`State=Hover`) | Fundo cinza claro |
| Pressed (`State=Pressed`) | Fundo escuro semitransparente, também no `:active` real |
| Foco | 🧩 Anel interno de 3px `Brand/Primary/Action` a 50%, só pelo teclado |
| Disabled | 🧩 Opacidade reduzida, sem clique |
