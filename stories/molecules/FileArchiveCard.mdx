# FileArchive1 / FileArchive2 (Figma: `molecule/FileArchive1` `1439:19655`, `molecule/FileArchive2` `1439:19656`)

## Uso

Miniatura de arquivo (ícone de pasta + rótulo) usada como thumbnail em
`molecule/FolderCard` e nas grades "Home-Grid"/"Organização". Use sempre
como thumbnail dentro de um card/grade, nunca como linha de lista (aí é
`FileList`).

## Um único componente para os dois nodes

`FileArchive1` e `FileArchive2` têm a mesma anatomia (ícone de pasta +
rótulo de 10px) e o mesmo asset visual — a única diferença é o conteúdo
(rótulo de exemplo) e o segundo tem `cursor-pointer` (affordance de clique).
Por isso um único componente `FileArchiveCard`, com props `label`/
`interactive`, cobre os dois casos em vez de duplicar a marcação.

## Estados

Elemento estático de exibição — o único estado interativo é o cursor de
clique (`interactive`) no segundo caso.

## Terminologia

Rótulo é conteúdo de exemplo ("Arquivo 1"/"Arquivo 3"), não texto fixo de
produto.
