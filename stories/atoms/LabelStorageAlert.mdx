# LabelStorageAlert (Figma: `atom/Label/Storage/Alert`, `1439:16885`)

## Uso

Selo/label de **alerta de armazenamento** com 4 variantes visuais — usado quando o sistema precisa chamar atenção pra um estado de espaço (quase cheio, cheio, etc.) dentro de um item ou card, tipicamente no fluxo de revisão de template sugerido.

## Variantes (`property1`)

| Valor | Rótulo | Alinhamento |
| --- | --- | --- |
| `default` | Incongruente | `items-end` |
| `variant2` | Incongruente | `items-center` |
| `variant3` | Incongruente | `items-end` |
| `variant4` | OK | `items-end` |

Cada variante usa um glifo próprio, com tamanho visual individual.

## Estados

Apenas `Default` por variante — badge de exibição estática, sem hover/active/disabled.
