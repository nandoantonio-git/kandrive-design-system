# PopoverNotification (Figma: `molecule/popover/Notification`, `1421:19626`)

## Uso

Popover para notificar mudanças de estado — por exemplo, uma organização
criada. Distinto de `Notification`, que é o toast avulso sem as várias
variantes. Use quando o usuário precisar abrir/revisar notificações
recentes, não pra um toast que desaparece sozinho.
