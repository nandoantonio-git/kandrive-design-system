# CleanSpaceListSelection

Figma: [`molecule/CleanSpaceListSelection`](https://www.figma.com/design/2g7udqxWbGA8F9Or7PGNg3/KanDrive-V0.2.1?node-id=1436-20496)

## Uso

Linha de seleção de arquivo grande dentro do fluxo "Liberar espaço"
(checkbox + ícone + nome/metadados + rótulo de tier). Peça específica desse
fluxo — não é um item de lista genérico; é composta diretamente em
`organism/CleanSpaceStorage`.

<Controls of={CleanSpaceListSelectionStories.Unselected} />

<Canvas of={CleanSpaceListSelectionStories.Interactive} />

## Anatomia

Checkbox + ícone de arquivo + nome e metadados do arquivo + prop `tier`
renderizada como `atom/StorageTierBadge` à direita (ex.: "Acesso rápido").

## Estados

<Canvas of={CleanSpaceListSelectionStories.Selected} />

| Estado | Tratamento |
| --- | --- |
| Não selecionado (`Selected=false`) | Checkbox vazio |
| Selecionado (`Selected=true`, prop `selected`) | Checkbox marcado |
| Hover, pressed, foco, disabled | Herdados de `atom/Checkbox`, que é o controle |

## Terminologia

"Acesso rápido" (via `atom/StorageTierBadge`) é o termo aprovado para esse
tier de armazenamento. Nome e metadados do arquivo são dados de amostra.
