# FileList (Figma: `molecule/FileList`, `666:9228`)

## Uso

Linha de lista de arquivo/pasta — ícone + nome [+ proprietário] [+ tamanho].
Use em qualquer visualização em **lista** (formatos `list`/`storage`/`list-sm`);
pra visualização em grade/thumbnail use `FileArchiveCard`.

## Anatomia

### Formatos

| Formato | Composição |
| --- | --- |
| `list` (padrão) | ícone + nome + Proprietário + Tamanho ("100MB") |
| `storage` | ícone + nome + Tamanho, sem coluna Proprietário |
| `list-sm` | ícone + nome + seta indicando navegação, sem Proprietário/Tamanho |

A prop `showIcon` mostra/esconde o ícone de arquivo.

## Estados

<Canvas of={FileListStories.Hover} />
<Canvas of={FileListStories.Pressed} />

| Estado | Tratamento |
| --- | --- |
| Idle (`State=Default`) | Fundo transparente |
| Hover (`State=Hover`) | Destaque de fundo |
| Pressed (`State=Pressed`) | Fundo de pressionado |
| Foco | 🧩 Anel de 3px `Brand/Primary/Action` a 50%, só pelo teclado |

Com `onClick`, a linha vira `role="button"` com `tabIndex=0` e Enter/Espaço. Disabled/loading/error não são suportados por este componente.

## Terminologia

Não renderiza texto fixo de produto — `fileName`/`owner`/`size` são
conteúdo de usuário.
