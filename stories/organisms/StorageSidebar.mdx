# StorageSidebar (Figma: `organism/StorageSidebar`, `635:5608`)

## Uso

Widget de status de armazenamento embutido na Sidebar, com atalhos pra gerir espaço/upgrade de plano. Use como versão compacta pra navegação lateral — pra a página completa de Armazenamento use `StorageStatusCurrent`.

## Terminologia

Este componente usa "Acesso rápido"/"Longo prazo" (termos aprovados) pra as tags de tier. O botão de gestão de espaço é "Gerir Espaço" em qualquer contexto — unificado em 2026-09-28 (antes o default deste componente era "Liberar Espaço", e só `organism/Sidebar` sobrescrevia via `manageSpaceLabel`; agora os dois usam o mesmo texto).

O rótulo do segundo botão, "Comprar Espaço", consta da lista aprovada da Regra 5 desde 2026-08-16 (antes era só um gap de cobertura). O tag "Corrente" (nome usado em outra variante do mesmo widget no Figma) não consta na lista de termos aprovados nem é termo proibido.
