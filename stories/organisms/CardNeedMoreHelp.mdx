# CardNeedMoreHelp (`organism/CardNeedMoreHelp`)

## Uso

Card de call-to-action pro suporte — use no fim de fluxos de ajuda/FAQ quando o usuário ainda não resolveu o problema.

<Canvas of={CardNeedMoreHelpStories.Default} />
<Controls />

## Composição

Heading "Ainda precisa de ajuda?" + parágrafo com link inline "suporte" + botão "Falar com o suporte". Usado como rodapé de contexto de ajuda.

O botão "Falar com o suporte" usa um chrome próprio (borda/fundo translúcido), não `atom/PushButton` — é um tratamento visual glass específico deste card, diferente das variantes padrão do `PushButton`.
