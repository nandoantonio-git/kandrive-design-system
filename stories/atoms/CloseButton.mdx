# CloseButton (Figma: `atom/CloseButton`, `1421:19008`)

## Uso

Botão circular pra **fechar** janelas, modais e popovers. Consumido por `Notification`/`PopoverNotification`/`ArchiveBrowserModal`/`Dialog/*` — use sempre que precisar de um botão de fechar padrão nesses contextos, em vez de recriar o círculo com um ícone solto.

<Controls />

## Anatomia

Círculo escuro com glifo "×" branco sobreposto, 2 tamanhos (`sm` 8px, `md` 16px). Responde a hover/press reais do mouse — não precisa de prop `state` controlada pra funcionar (a prop existe só pra fixar um estado nas stories).

## Estados

`Idle` · `Hover` · `Pressed` — via CSS real (`:hover`/`:active`) ou via prop `state` pra documentação estática. Sem disabled/loading/error.

## Terminologia

Não renderiza texto visível; `label="Fechar"` é só acessibilidade.
