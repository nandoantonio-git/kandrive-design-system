# DropdownSelectGroupBy (Figma: `molecule/DropdownSelect/GroupBy`, `1421:18719`)

## Uso

Dropdown "Agrupar por" — usado para selecionar o critério de agrupamento do
grid/lista de arquivos. Não confundir com `DropdownSelectLabel` (dropdown
de etiquetar) — são 2 componentes distintos, mesmo parecidos.

<Canvas of={DropdownSelectGroupByStories.Default} />
<Controls />

## Anatomia

Rótulo de seção "AGRUPAR" + botão "Agrupar" com ícone de agrupamento +,
quando expandido, uma lista de 4 opções: "Data de modificação", "Tipo",
"Tamanho", "Data de adição". Cada opção da lista é renderizada pelo
componente `DropdownSelectGroupByItem` (ver [documentação
própria](../atoms/DropdownSelectGroupByItem.mdx)).

<Canvas of={DropdownSelectGroupByStories.Expanded} />
<Canvas of={DropdownSelectGroupByStories.Disabled} />

## Estados

- `default` — fechado
- `expanded` — aberto, mostrando as 4 opções
- `disabled` — desabilitado (opacidade reduzida)

Não há estado de hover próprio documentado neste componente.

## Terminologia

"AGRUPAR"/"Agrupar"/"Tipo"/"Data de modificação"/"Tamanho"/"Data de adição"
são texto do produto — vocabulário de organização de arquivos, sem
restrições de terminologia aplicáveis.
