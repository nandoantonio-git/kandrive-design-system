# SidebarToggle (`organism/sidebar-toggle`)

## Uso

Controle de expandir/colapsar a seção de armazenamento dentro da Sidebar — use só nesse contexto específico, não é um toggle genérico de collapse. Label "Armazenamento", com ícone de nuvem à esquerda.

<Canvas of={SidebarToggleStories.Expanded} />
<Controls />

## Composição

Usado dentro de `organism/storage-sidebar` — não é um componente standalone de uso geral.

Não é um botão de ação de fluxo — é um disclosure trigger (expande/colapsa conteúdo), não usa `atom/PushButton`.

## Estados

Idle · Hover · Pressed, combinados com o eixo `isExpanded` (`true`/`false`). O chevron gira ao expandir/colapsar (transição CSS nativa, reversível a qualquer momento).

## Terminologia

"Armazenamento" é o nome literal da seção — não está na lista de termos travados, mas também não é termo proibido.
