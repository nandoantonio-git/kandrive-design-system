# FreeModeAddMenu (Figma: `molecule/FreeModeAddMenu`, `1394:16574`)

## Uso

Dropup list com as opções de nó disponíveis pra adicionar no canvas Modo Livre (descrição Figma verbatim: *"dropup list com opções de nodos disponíveis de adição na aba de modo livre de template"*). Aberto pelo botão "Adicionar nodo" de [Templates/OrganizeFreeModeCanvas](../templates/OrganizeFreeModeCanvas.mdx). Extraído como symbol Figma próprio em 2026-08-20 (antes só existia inline dentro do template; citado antes como `molecule/Menuitem/freemodeOrganization`).

### Histórico

**🔧 Corrigido em 2026-08-23.** Releitura completa (não mais screenshot isolado) confirmou regressão real: painel `228px` em Liquid Glass claro (`bg-effect-glass-white-50` + `.glass-edge`/`.glass-shadow-sm`, Regra 10), não o fundo sólido `zinc-900`/`zinc-700` que estava implementado (herdado de antes do symbol Figma próprio, 2026-08-20). `FreeModeListItem` já usava `text-zinc-700`, correto pro fundo claro — só o container precisava de correção.

## Estados

Os estados (hover, pressed, foco, disabled) são os de cada `FreeModeListItem`. Escolher uma operação chama `onSelect` com ela.
