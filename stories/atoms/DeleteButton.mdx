# DeleteButton (`atom/DeleteButton`)

## Uso

Ícone-botão sem chrome de borda pra **ações destrutivas** pontuais (remover um item de uma lista, por exemplo) — diferente do `PushButton` com `isDestructive`, que é pra ação primária de destruição de uma tela inteira (ex. "Excluir" num modal).


Ícone-botão para ações destrutivas — sem chrome de borda, alvo de clique
independente do `PushButton`.

## Regra 1 — não é conflito

Não é `button/primary`/`secondary`/`destructive`: é um átomo de ícone sem
chrome de botão, com destino de clique independente do `PushButton` (achado
#11, `figma-inventory.md`). Ver `Atoms/PushButton` para o botão de ação
primária.

## Estados

`style` Figma-confirmado: `Default`|`Red`|`White` — implementado 1:1.
`state` Figma-confirmado: `On`|`Idle`|`Clicked`|`Disabled`. `On`/`Idle` não
têm diferença de comportamento descrita no Figma (gap, Regra 9: não
inventado) — ambos mapeiam para o mesmo repouso visual. `Clicked` é o
`:active` nativo (feedback de press via `scale-90`).
