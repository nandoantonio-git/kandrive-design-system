# FileRow (Figma: sem node confirmado)

O JSDoc descreve `molecule/FileRow` `Device=Mobile` como Figma-confirmado no KanDrive V0.2.1, mas não cita o id do nó.

## Uso

A linha da lista de arquivos no mobile: a Home em modo Lista e o grupo do `FolderCard` no mobile (`Organize/Saved/Mobile`). No desktop e no tablet, a lista usa `FileList`.
