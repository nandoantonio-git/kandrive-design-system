# FreeModeListItem (Figma: `molecule/FreeModeListItem`, `1394:16408`)

## Uso

Linha da lista de tipos de nó disponíveis para adicionar ao canvas Modo
Livre — o menu que abre a partir do botão "Adicionar nodo" de
[`celule/FreeModeButtons`](./FreeModeButtons.mdx). Aparece só dentro desse
menu — não é reutilizado em outras listas do produto.

## Anatomia

### Operações

Junção, Subtração, Interssecção, Exclusão, Filtrar por tamanho, Filtrar
por formato, Filtrar por data (prop `operation`).

## Estados

<Canvas of={FreeModeListItemStories.Hover} />
<Canvas of={FreeModeListItemStories.Selected} />

- `idle` — transparente
- `hover` — fundo cinza claro
- `selected`/`pressed` — fundo escuro semitransparente (Figma chama esse eixo de `Clicked`; normalizado no código pra bater com o resto do catálogo)

| Estado | Tratamento |
| --- | --- |
| Default (`State=Default`) | Transparente |
| Hover (`State=Hover`) | Fundo cinza claro |
| Pressed (`State=Pressed`) / `selected` | Fundo escuro semitransparente, também no `:active` real; clique alterna `selected` (`aria-pressed`) |
| Foco | 🧩 Anel de 3px `Brand/Primary/Action` a 50%, só pelo teclado |
| Disabled | 🧩 Opacidade reduzida, sem clique |

## Terminologia

Os rótulos das 7 operações são o texto real usado no produto.
