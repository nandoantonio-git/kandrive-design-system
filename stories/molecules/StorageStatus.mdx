# StorageStatus (Figma: `molecule/StorageStatus`, `231:4553`)

## Uso

Widget de status de armazenamento (totais por tier) — usado no **Sidebar**
pra dar visão geral rápida de uso. Pra a página completa de Armazenamento,
com detalhe de curto prazo, use `StorageStatusCurrent` + `StorageBar`
diretamente.

## Anatomia

### Variante `Expanded` — seletor de escopo

Tem 3 painéis (Figma: `Tier=Global/Current/LongTerm`; texto na tela "Total"/
"Acesso rápido"/"Longo prazo") que funcionam como um seletor: o painel
ativo mostra um chip preenchido com a cor da categoria, os outros 2
aparecem como chips outline clicáveis para trocar de painel. O botão
"Gerir espaço" só aparece no painel "Total" — termo aprovado para esta
página (Armazenamento) — e abre o modal de limpeza de espaço.

🧩 O chip "Total" mostra "Global" no Figma — traduzido na revisão de UX
writing (2026-09-28): a definição de tom de voz proíbe "Global" como
rótulo de UI ("usar Total").

No painel "Total", a barra é segmentada por tipo de arquivo, com legenda
(Imagens/Documentos/Vídeos/Outros) logo abaixo usando as mesmas cores dos
segmentos. Nos painéis "Acesso rápido" e "Longo prazo", aparece uma
legenda de 2 itens abaixo da barra: "XX em uso" e "XX Livre".

### Variante `Sidebar` — versão compacta

<Canvas of={StorageStatusStories.Sidebar} />

Mostra só 1 tag ("Longo Prazo") + barra + texto de uso. Não expõe o
seletor de escopo nem botões de ação.

## Estados

<Canvas of={StorageStatusStories.LimitReached} />

| Estado | Tratamento |
| --- | --- |
| `scope` (`global`/`current`/`long-term`, valores internos da prop) | Alterna entre os 3 painéis da variante Expanded (Figma `Tier=Global/Current/LongTerm`; texto "Total"/"Acesso rápido"/"Longo prazo") |
| `variant="sidebar"` | Versão compacta (`Layout=Sidebar`) |
| Limite atingido (`limitReached`, `Tier=Alert`) | Valor e aviso em vermelho, barra cheia |
| Hover/Active/Foco (chips, botões) | Herdados dos componentes filhos (`ScopeTypeLabel`, `Button`) |

**Limite atingido.** `limitReached` (Figma `Tier=Alert`, `1765:62468`, V0.2.1), só no escopo global: o valor usado em `Brand/Feedback/Danger/Default`, o aviso "Seu limite de X foi totalmente atingido…" abaixo dos botões (16px, Regra 4) e a barra cheia em `Brand/Feedback/Danger/Surface`. ⚠️ No componente do Figma, o aviso usa `Danger/Subtle` (35%, ilegível); a tela `Storage/LimitReached` usa o vermelho cheio, que é o que o código segue.

Os estados `NearLimit`/`Empty` mencionados na descrição do
componente não estão implementados — sem especificação visual confirmada
para eles.

## Terminologia

"Gerir espaço" é aprovado no contexto desta página (Armazenamento).
"Comprar espaço" também aparece como rótulo de botão. Nenhum termo
proibido é usado.
