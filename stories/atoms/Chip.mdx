### Tipografia

O texto tem 12px: é microtexto de rótulo de navegação, dentro da exceção da Regra 4. Com toque, a área clicável cresce até 44px.

## Estados

| Estado | Tratamento |
| --- | --- |
| Desmarcado / Marcado | Figma `Selected=false/true` |
| Hover | Fundo do desmarcado; 🧩 hover do marcado (Regra 8) |
| Pressed 🧩 | `active:opacity-70` (Regra 8) |
| Foco | Anel `ring-3 brand-teal-action/50`, só pelo teclado |
| Disabled 🧩 | 50% de opacidade, sem ponteiro (Regra 8) |
| Transição | Cor e opacidade animadas |

## Terminologia

O rótulo é conteúdo livre: cada uso passa o nome da seção (ex.: as seções de Settings/Payment em `MobileFooterSettings`).
