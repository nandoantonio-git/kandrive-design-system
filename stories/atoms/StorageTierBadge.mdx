# StorageTierBadge (`atom/StorageTierBadge`)

## Uso

Selo por-arquivo indicando o tier de armazenamento do item (Acesso Rápido/Longo Prazo) — usado dentro de `organism/CleanSpaceStorage`, no escopo de um item individual. Não é um controle de navegação/filtro: a segmentação sistêmica entre arquivos "correntes" e "de longo prazo" continua sendo resolvida por pasta/diretório no sistema de arquivos — este badge só rotula o tier do item numa tela de detalhe.

## Rótulos

| Valor da prop `tier` | Rótulo exibido |
| --- | --- |
| `current` | Acesso rápido |
| `long term` | Longo prazo |

## Estados

Elemento de exibição estática — não há hover/pressed/disabled, só o rótulo com o tier do arquivo.
