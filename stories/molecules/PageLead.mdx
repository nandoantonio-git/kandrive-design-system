# PageLead

Figma: [`molecule/PageLead`](https://www.figma.com/design/2g7udqxWbGA8F9Or7PGNg3/KanDrive-V0.2.1?node-id=1245-12212)

## Uso

Cabeçalho de página (título H1 + legenda) — reutilizável no topo de toda
página de nível superior do produto (Armazenamento, Configurações de Plano
etc.). Para sub-seções internas, use `Type/Heading/*` diretamente, não
este componente.

<Controls of={PageLeadStories.Default} />

## Anatomia

### Props

`title` é obrigatório — cada página define seu próprio H1. `caption` tem
um valor padrão ("Gerencie seu armazenamento") mas pode ser sobrescrito
por página.

<Canvas of={PageLeadStories.OtherPage} />

## Estados

Sem estados interativos. Componente estático (título/legenda), sem interação.

## Terminologia

O título e a legenda são conteúdo de cada página ("Armazenamento", "Gerencie seu armazenamento", "Configurações de Plano"…). Nenhum termo proibido (Regra 5).
