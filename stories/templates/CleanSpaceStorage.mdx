# CleanSpaceStorage

Figma: [`template/cleanSpaceStorage/Device=Desktop`](https://www.figma.com/design/2g7udqxWbGA8F9Or7PGNg3/KanDrive-V0.2.1?node-id=1439-16908)

## Uso

Modal "Liberar espaço" — lista arquivos grandes/duplicados pra o usuário liberar espaço. Abre a partir do botão "Liberar espaço" da página Status de armazenamento (e de Configurações). O botão "Gerir espaço" da Sidebar não abre este modal: leva à página Status de armazenamento.

## Composição

Tags de tier reusam `atom/StorageTierBadge` em vez de markup duplicado — rótulos "Acesso rápido"/"Longo prazo". Botões "Excluir"/"Excluir cópias" usam `atom/Button` (`variant="outline"`, migrado de `PushButton isDestructive`) — chrome neutro/glass, só o texto na cor de destrutivo, nunca fundo vermelho. "Selecionar todos" usa o padrão (`primary`); "Desfazer seleção" fica `disabled` (estado lido/neutro).

### Material

Container e seções usam o material Liquid Glass — ver [Tokens/Materials](../tokens/Materials.mdx).

## Estados

- Seleção de arquivos: checkboxes + "Selecionar todos"/"Desfazer seleção"
- Prévia de duplicados: badge "Prévia" com aviso de que a detecção é ilustrativa — os grupos de duplicados mostrados são exemplos, não uma detecção real

| Estado | Tratamento |
| --- | --- |
| Hover / Pressed / Foco / Disabled | herdados de `CleanSpaceLargeFiles`, `CleanSpaceDuplicated` e `atom/Button` |

## Terminologia

"Acesso rápido"/"Longo prazo" e "Liberar espaço" são termos aprovados neste contexto (Armazenamento/Config. de Plano).
