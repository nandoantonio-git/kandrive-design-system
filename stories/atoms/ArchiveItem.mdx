# ArchiveItem (Figma: `molecule/FileItem`, `212:3691`)

## Uso

Linha/card compacto pra representar **um arquivo arquivado** dentro de uma lista — ícone de tipo, nome e controle de seleção. Use dentro de listas de arquivos onde cada item precisa ser selecionável (`idle`/`hover`/`pressed`/`selected`/`disabled`). Mesma anatomia de `FolderItem`/`ImageItem`/`VideoItem`, um por tipo de conteúdo — escolha pelo tipo real do arquivo, não misture. No Figma, os 4 são o eixo `Type` (`File`/`Folder`/`Image`/`Video`) do mesmo set `molecule/FileItem`.

## Anatomia

Glifo 3D-glass de arquivo (36.68×41px) + nome de 10px abaixo + badge de seleção opcional no canto inferior direito (reusa `atom/SelectState`, não reimplementado).

### Sobre o eixo `tier`

Não existe uma prop `tier` neste componente. Pra mostrar o tier de armazenamento de um arquivo (Acesso Rápido/Longo Prazo), componha com `atom/StorageTierBadge` por fora — não é um estado interno do `ArchiveItem`.

## Estados

`idle` · `hover` · `pressed` · `disabled` · `selected` · `selected-hover` · `selected-pressed`

| Estado | Tratamento |
| --- | --- |
| Hover | Glifo de hover do Figma (`State=Hover`) |
| Pressed | Glifo de pressed do Figma (`State=Pressed`) |
| Selected / Selected-Hover / Selected-Pressed | Glifo do estado + `atom/SelectState` no canto |
| Foco 🧩 | Anel `ring-3 brand-teal-action/50`, só pelo teclado (Regra 8) |
| Disabled | Glifo + overlay de disabled do Figma (`State=Disabled`), `aria-disabled` |
| Transição | Sem transição CSS: os estados trocam o SVG (`src`), o que não é animável |

### Interação

Sem `state` fixo — passe o mouse, clique/pressione Enter pra selecionar de verdade (não é freeze-frame). `state` continua disponível como override pra congelar um estado específico em documentação/auditoria.
