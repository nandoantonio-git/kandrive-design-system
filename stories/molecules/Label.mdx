# Label

Figma: [`molecule/Label`](https://www.figma.com/design/2g7udqxWbGA8F9Or7PGNg3/KanDrive-V0.2.1?node-id=302-12809)

## Uso

Pílula de dropdown de etiquetas. Use nos fluxos gerais de etiquetagem de
arquivo — inclusive dentro do canvas de organização, onde antes existia um
componente separado (`DropdownSelectLabel`). Sem `state`, abre e fecha sozinho pelo clique.

<Controls of={LabelStories.Default} />

## Anatomia

Legenda "ETIQUETAR" + pílula com ícone de etiqueta, fundo Liquid Glass e
chevron. Quando expandida, tem 2 modos (prop `labels`):
- **Sem `labels`** (padrão) — campo de busca mini + lista fixa de badges por
  tipo de arquivo (Documentos/Imagens/Vídeos) + item "+ Nova Etiqueta".
- **Com `labels`** (mesmo array vazio) — lista dinâmica das etiquetas
  informadas + item "+ Nova Etiqueta" (`onValueChange` seleciona).

<Canvas of={LabelStories.ExpandedDynamicList} />

### Histórico

Consolidados numa API só: `dropdown-select-label.tsx`
foi removido (sem consumidor real além da própria story) e absorvido aqui
via a prop `labels`. Pequena divergência assumida conscientemente: o
chevron caret (`LabelChevronGlyph`) deste node passou a ser usado nos 2
modos, em vez da seta triangular (`ArrowDropDown`) que `DropdownSelectLabel`
usava — não há mais 2 implementações pra manter sincronizadas.

## Estados

<Canvas of={LabelStories.Expanded} />
<Canvas of={LabelStories.Disabled} />

- `default` — fechado
- `expanded` — aberto, mostrando busca e lista de etiquetas (ou lista
  dinâmica de `labels`, se informado)
- `disabled`

| Estado | Tratamento |
| --- | --- |
| Default (`Expanded=false`) | Fechado |
| Expandido (`Expanded=true`) | Aberto; escolher uma opção atualiza a pílula e fecha |
| Disabled (`State=Disabled`) | Opacidade reduzida, sem clique |
| Hover | Fundo `#71717a33` na pílula |
| Pressed | Feedback no `:active` |
| Foco | 🧩 Anel de 3px `Brand/Primary/Action` a 50% nos 2 gatilhos, nas opções e na busca, só pelo teclado |
| Fechar com Esc / clique fora | 🧩 Extensão de engenharia |
| Busca | 🧩 `<input>` de verdade que filtra as opções |

## Terminologia

"Etiquetar"/"ETIQUETAR" são vocabulário de rotulagem de arquivo, sem
restrições de terminologia aplicáveis.
