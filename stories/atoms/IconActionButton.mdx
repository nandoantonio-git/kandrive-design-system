# IconActionButton

Figma: [`atom/IconButton`](https://www.figma.com/design/2g7udqxWbGA8F9Or7PGNg3/KanDrive-V0.2.1?node-id=174-384)

## Uso

Base de código compartilhada dos ícones-botão sem chrome de borda — **não é um átomo do Figma por si só**, é a anatomia comum do set `atom/IconButton` extraída para não duplicar o mesmo botão 5 vezes. É a base de:

- [ClearButton](?path=/docs/atoms-ações-iconbutton-clear--docs) — cancelar (`Icon=Clear`)
- [ConfirmButton](?path=/docs/atoms-ações-iconbutton-confirm--docs) — confirmar (`Icon=Confirm`)
- [DeleteButton](?path=/docs/atoms-ações-iconbutton-delete--docs) — ação destrutiva pontual (`Icon=Delete`)
- [KeepButton](?path=/docs/atoms-ações-iconbutton-keep--docs) — guardar em longo prazo (`Icon=Keep`)
- [PlusButton](?path=/docs/atoms-ações-iconbutton-plus--docs) — ação aditiva pontual (`Icon=Plus`)

Em tela, use sempre um desses 5 átomos: eles já trazem o glifo, o `aria-label` e as cores do Figma. Use a base diretamente só para criar um novo ícone-botão do mesmo set.

## Anatomia

Glifo centralizado (`size-5` por padrão, ajustável via `iconClassName`), sem borda, dentro de um alvo de toque circular de 32px (piso de acessibilidade — nenhum dos 5 tem essa medida confirmada no Figma; mantida por ser área de toque, não elemento visual).

### Props

| Prop | Papel |
| --- | --- |
| `icon` | Componente SVG do glifo (obrigatório) |
| `label` | Nome acessível (`aria-label`) — obrigatório, porque o botão só renderiza um ícone |
| `iconClassName` | Tamanho visual do SVG; o alvo de toque continua 32px |
| `className` | Cor do glifo e, se houver, fundo de hover — cada átomo consumidor define o seu |

## Estados

| Estado | Tratamento |
| --- | --- |
| Hover | Nenhum na base — opt-in por átomo via `className` |
| Pressed | `motion-safe:active:scale-90` |
| Foco 🧩 | Anel `ring-3 brand-teal-action/50`, só pelo teclado (Regra 8) — herdado pelos 5 átomos |
| Disabled | 40% de opacidade, sem ponteiro |
| Transição | `transition-all` |

## Terminologia

Sem texto fixo de produto — o `label` é obrigatório e cada átomo consumidor passa o seu ("Cancelar", "Confirmar", "Excluir", "Guardar em longo prazo", "Adicionar").
