# CleanSpaceStorage (`organism/cleanSpaceStorage`)

## Uso

Modal do fluxo "Liberar Espaço" — lista arquivos grandes/duplicados pra o usuário liberar espaço. Abre a partir do botão "Liberar Espaço" (Armazenamento/Config. de Plano) ou "Gerir Espaço" (Sidebar) — mesmo modal, gatilhos com nomes diferentes por contexto.

## Composição

Tags de tier reusam `atom/StorageTierBadge` em vez de markup duplicado — rótulos "Acesso rápido"/"Longo prazo". Botões "Excluir"/"Excluir cópias" usam `atom/PushButton` (`variant="neutral"`, `isDestructive`) — chrome neutro/glass, só o texto na cor de destrutivo, nunca fundo vermelho. "Selecionar todos" usa `variant="primary"`; "Desfazer seleção" fica `disabled` (estado lido/neutro).

## Estados

- Seleção de arquivos: checkboxes + "Selecionar todos"/"Desfazer seleção"
- Prévia de duplicados: badge "Prévia" com aviso de que a detecção é ilustrativa — os grupos de duplicados mostrados são exemplos, não uma detecção real

## Material

Container e seções usam o material Liquid Glass — ver [Tokens/Materials](../tokens/Materials.mdx).

## Terminologia

"Acesso rápido"/"Longo prazo" e "Liberar Espaço" são termos aprovados neste contexto (Armazenamento/Config. de Plano).
